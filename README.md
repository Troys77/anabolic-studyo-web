# ANABOLIC STUDIO
### Independent Game Development Studio

**Anabolic Studio**, dört kişilik bağımsız bir oyun geliştirme ekibidir. Yaratıcı hikâye anlatımını, atmosferik tasarımı ve etkileşimli deneyimleri bir araya getirerek oyunculara özgün dijital dünyalar sunmayı hedefliyoruz.

Bu repository, Anabolic Studio'nun dijital kimliğini yansıtan resmî tanıtım web sitesinin kaynak kodlarını içermektedir.

---

## Proje Hakkında

Anabolic Studio web sitesi; stüdyomuzun projelerini, geliştirme süreçlerini ve duyurularını tek bir platformda sunmak amacıyla tasarlanmıştır.

Modern web tasarım prensipleri doğrultusunda geliştirilen proje, sade kullanıcı deneyimini güçlü bir görsel kimlikle birleştirir.

## Teknolojiler

| Teknoloji | Kullanım Amacı |
|---|---|
| HTML5 | Sayfa yapısı ve semantik içerik |
| CSS | Arayüz tasarımı, animasyonlar ve responsive düzen |
| JavaScript | Dinamik içerikler ve kullanıcı etkileşimleri |
| Git | Sürüm kontrolü |
| GitHub | Kaynak kod yönetimi ve proje paylaşımı |

## Temel Özellikler

- **Modern Arayüz:** Koyu tema, mor vurgu renkleri ve tutarlı tasarım dili.
- **Çok Sayfalı Mimari:** Oyunlar, duyurular, stüdyo tanıtımı ve iletişim bölümleri.
- **Etkileşimli Galeri:** JavaScript destekli görsel değiştirme ve otomatik geçiş sistemi.
- **Responsive Tasarım:** Farklı ekran boyutlarına uyum sağlayan sayfa düzenleri.
- **Kullanıcı Deneyimi:** Hover efektleri, geçiş animasyonları ve anlaşılır navigasyon.
- **Modüler Dosya Yapısı:** HTML, CSS, JavaScript ve medya dosyalarının düzenli organizasyonu.

## Tasarım Yaklaşımı

Projenin görsel dili, modern oyun stüdyolarının dijital kimliğinden ilham alır.

**Tasarım prensipleri:**
- Minimalist ve içerik odaklı yerleşim
- Koyu arka plan ve mor vurgu renkleri
- Montserrat tipografi ailesi
- Tutarlı kart, buton ve navigasyon bileşenleri
- Akıcı geçişler ve etkileşimli görsel öğeler

## Yerel Ortamda Çalıştırma

Projeyi bilgisayarınıza indirmek için:

```bash
git clone https://github.com/Troys77/anabolic-studyo-web.git
```

Proje klasörüne geçin:

```bash
cd anabolic-studyo-web
```

Ardından `index.html` dosyasını tarayıcınızda açın veya VS Code Live Server eklentisini kullanın.

Proje, HTML, CSS ve JavaScript ile geliştirildiği için ek bir backend kurulumu gerektirmez.

## Geliştirme ve Proje Durumu

Bu web sitesi, eğitim kapsamında geliştirilen bir frontend projesidir. Geliştirme sürecinde temel web teknolojileri, responsive tasarım, kullanıcı etkileşimleri ve Git tabanlı sürüm kontrolü üzerine çalışılmıştır.

Proje, yeni içerikler ve arayüz iyileştirmeleriyle geliştirilmeye açıktır.
